中文优先的 AI Agent 技能合集

四个互不依赖的独立技能。每个都能单独装、单独用，不串流程、不共享配置。共同点是：都从真实返工里长出来，都带可跑的门禁脚本。

查看源码 技能说明

四个技能

law-text-ingest

法律 PDF 入库：先判版本时效，再用脚本提取编章结构，最后逐条回原文核对留痕。条号是定位坐标，错一位全错。

Python 标准库

comfyui-local-zimage

Windows 本机 ComfyUI 免费出图。覆盖模型分段下载、8GB 显存降级、img2img 锁脸、剧本到 MP4 的全链路。

Windows + NVIDIA

diagram-layout-discipline

画 SVG 图的三条硬纪律：文字不许溢出、嵌套容器要能分清、能画的逻辑不许用文字描述。附文字宽度实测脚本。

Python + Pillow

chinese-report-voice

给评委看的文档先判文体：报告体、技术文档、口播稿三套语体不能混。附文风扫查与 PDF 排版体检两个门禁。

Python + docx/pdf

怎么装

git clone https://github.com/zhanguoliang715/ai-agent-skills-cn.git
cp -r ai-agent-skills-cn/skills/<技能名> ~/.workbuddy/skills/

只想要一个，就只拷那一个目录。

跟流水线仓库的区别

agent-pipeline-skills 是十棒串行流水线，技能之间有强制前后依赖，产物按 01- 到 09- 固定命名。本仓库只收「单独拿出来就能用」的技能——四个技能之间没有调用关系，删掉任意三个，剩下的照常工作。

这些技能不是通用的

每条规则都绑定具体场景：法律文本的"逐条核对"换成科普文章就是浪费；8GB 显存的降级参数换到 24GB 卡上就是画质损失；报告体语体拿去写教程会显得生硬。各技能 SKILL.md 都写了适用范围段，换领域请换规则，不要指望一套通用。
