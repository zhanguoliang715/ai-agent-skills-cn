AI Agent 技能索引

这里不放技能，只放索引。每个技能一个独立仓库——一个链接对应一个技能，想分享哪个发哪个。

为什么拆成一技能一库

早先四个技能挤在一个仓库里：分享时没法只给一个，别人 clone 下来还得自己挑；Star、Issue、版本也混在一起。四个技能互不调用，没有理由共享仓库。现在的规矩：有数据流依赖的才住一起，其余一律独立。

四个独立技能

law-text-ingest

法律 PDF 入库。先判版本时效，再用脚本提取编章结构，最后逐条回原文核对留痕——条号是定位坐标，错一位全错。

Python 标准库

comfyui-local-zimage

Windows 本机 ComfyUI 免费出图。治三个卡点：装不上、下不动、显存爆；带三个可导入工作流与剧本到 MP4 的链路。

Windows + NVIDIA

diagram-layout-discipline

画 SVG 图的三条硬纪律：文字不许溢出、嵌套容器要能分清、能画的逻辑不许写成文字。附量字宽脚本与断言骨架。

Python 标准库

chinese-report-voice

给评委看的中文文档先判文体：报告体 / 技术文档 / 口播稿三套语体不能混。附文风扫查与 PDF 排版体检两道门禁。

Python（docx/pdf 可选库）

怎么用

# 只要一个技能，就只 clone 那一个
git clone https://github.com/zhanguoliang715/law-text-ingest.git
cp -r law-text-ingest ~/.workbuddy/skills/

每个技能仓库都带三样东西：SKILL.md（规则原文）、docs/新手手册.md（怎么做、为什么）、docs/技术文档.md（契约、边界、失败模式）。
